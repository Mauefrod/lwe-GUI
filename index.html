§6–7 · Modos de Operación y Ciclo Completo
§6 · Modos Especiales
MODO WINDOW
--window 0x0xWIDTHxHEIGHT
apply_wallpaper() + --window param xdotool windowsize → fijar resolución custom
MODO RANDOM
checkbox "random" → config["--random"]=true auto-disable: "--delay".active = false "--set".active = false
MODO DELAY (auto-rotate)
spinner input → config["--delay"]["timer"]="30" cmd_auto_random() → loop infinito DAEMON
MODO FAVORITOS
Right-click wallpaper → "Add to Favorites" GroupManager.toggle_favorite(id) config["--favorites"].append(id) ConfigManager.save(config)
MODO GRUPOS
Crear "Nature": config["--groups"]["Nature"]=[w1,w2] Seleccionar grupo en dropdown: config["--set"]["wallpaper"] = from_group apply_wallpaper()
